Build delivery workflows for Steadfast Courier merchants. Create consignments,
track parcels, manage return requests, and review account balances.

All requests and responses use JSON. Use the **Authorize** button to add your
`Api-Key` and `Secret-Key` before trying an endpoint. Get both credentials
from the [Steadfast merchant panel](https://steadfast.com.bd/login).
